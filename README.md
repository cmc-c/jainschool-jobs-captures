# jainschool-jobs-captures

자인스쿨 채용공고 안내 스레드(@ja_in_school)에 첨부하는 **공고 세부내용 캡처 이미지 저장소**입니다.

## 이 저장소는 무엇인가

자인스쿨은 기업 공식 채용페이지에 새로 올라온 공고를 스레드로 안내합니다. 글에는
공고 제목·마감기한·핵심 내용과 **공식 공고 URL** 이 함께 실립니다. 지원자가 조건을
한눈에 확인할 수 있도록, 공고 원문에서 자격요건·전형절차 같은 **핵심 정보 영역만 잘라
이미지로 첨부**합니다. 그 이미지들이 여기에 있습니다.

## 왜 공개 저장소인가

Threads(Meta) 의 이미지 첨부 API 는 **공개 인터넷에서 접근 가능한 이미지 주소**만 받습니다.
메타 서버가 그 주소로 직접 이미지를 가져가는 구조라 비공개 저장소나 로그인이 필요한
주소는 쓸 수 없습니다. 이 저장소가 공개인 이유는 그것뿐이며, 사람이 찾아와 열람하도록
만든 곳이 아닙니다.

## 이미지 출처와 이용 범위

- 모든 이미지는 **각 기업이 자사 공식 채용페이지에 공개한 채용공고**의 일부입니다.
  저작권은 해당 기업에 있습니다.
- 공고 전문을 옮기지 않고 지원자가 확인해야 할 조건 부분만 인용하며, 함께 발행되는
  스레드 글에 **공식 공고 URL 을 반드시 표기**합니다.
- 캡처 영역에 담당자 이름·이메일·전화번호 같은 개인정보가 보이면 그 캡처는 자동으로
  폐기되고, 이미지 없이 글만 발행됩니다.
- 이미지는 안내 목적으로만 쓰며 판매·재배포·2차 가공을 하지 않습니다.

## 보존 정책

캡처는 **30일이 지나면 자동으로 삭제**됩니다. 채용공고는 마감되면 안내할 이유가
없어지므로 필요 이상으로 보관하지 않습니다.

**요청을 받으면 별도 검토 없이 즉시 삭제**하고, 해당 공고의 스레드 게시물도 함께
